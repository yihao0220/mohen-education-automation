# 数学类项目（清艳五年级 / 南城二小 / 安乡金海初二）

先读 [通用录入规则.md](通用录入规则.md) —— 其中「数学类答案」一节是本类项目的核心规则，本文件只补各校差异。

## 数学通用（重要，优先看通用规则里的这三条）

- 能稳定转纯文本的留答案区，公式对象/富文本风险/会乱码的转解析区承载。
- 斜体 Unicode 字母 `𝑥 𝑦 𝑏 𝑘` 在清洗阶段归一化成普通字母，避免录题侧显示成方框。**不要误判成公式对象。**
- 富文本模板清洗后若要保公式，跳过纯文本题答重写链路；误走该链路时优先怀疑公式对象被写没。
