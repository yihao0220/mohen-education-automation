# 未来 高二 生物

先读 [通用录入规则.md](通用录入规则.md)，本文件只写未来生物独有的部分。

## 题目录入

使用 `理科 + future_biology` 覆盖层。

- 每个**顶层阿拉伯题号**是一道 F1；`(1)(2)(3)` 不拆题。
- 题干、选项、题图、原生表格和公式随题保留。
- 不录入：试卷标题、分值说明、题组标题、选择题/非选择题标题、章节横幅、「对点训练」、「综合强化」。

状态：已只读审计 52 份、764 道题，结构标题和已确认装饰媒体污染均为 0。Mac Quick Look 仅开发预览，**Windows WPS 最终 Range 和插件 F1 仍待核对**。

## 答案必须分两步，不能跳步

### 第一步：按「课时对点练」截取边界

`tools/trim_future_biology_answers.py`

- **输出只是中间文档，不等于答案清洗。**
- 只扫描 `选必一答案`、`选必二答案`，排除 WPS 锁文件。
- 边界唯一依据是「课时对点练」图片字段或可见文字标记。
- 命中的输出到 `答案/按课时截取/`；无标记的其他文档族跳过。
- 标记重复、标记位于表格、同行出现未知内容、标记后缺答案/解析 → **整批停止，不覆盖原答案**。
- 先 `--dry-run` 预演，参数用 `--expected-source-count 73 --expected-matched-count 42`。

### 第二步：标准化清洗

`tools/clean_future_biology_answers.py`

- 先 `--preflight-only` 只读预检，参数 `--expected-source-count 42 --expected-question-count 580`。
- 删除题干、选项、题组标题、题干表格和装饰媒体；保留答案/解析的富文本与图片公式；补齐空解析。
- 标准结构：`题号 → 答案： → 解析：`。
- 输出在 `答案/已清洗/`，审核清单在 `答案/审核清单/`，审核状态 JSON 与 `_已清洗.docx` 同目录。

状态：42 份、580 题离线门禁通过；Windows WPS F2/F3/F4 待验证。

## Mac → Windows 跨机交付

**不要用 Finder 直接压缩中文目录。** 必须用 `tools/package_future_biology_answers.py`：

- 外层 ZIP 用英文文件名，固定 `future_biology_cleaned_answers_windows.zip`。
- 内部路径用 NFC + UTF-8，排除 `.DS_Store` / `__MACOSX`。
- 打包前必须 42/42 份审核门禁通过（`--expected-docx-count 42`）。
- 审核签名用 size + SHA256，所以解压后路径和修改时间变化不会误报，DOCX 内容变化仍立即失效。
