# 众美 高三 语文（对点练 / 文言文）

先读 [通用录入规则.md](通用录入规则.md)，本文件只写众美语文独有的部分。

## 路径识别

项目上下文识别**只依赖稳定前缀 `众美-高三-语文`**，不得绑定人员后缀。项目总目录改名后必须同步默认路径，并重新刷新与绝对路径签名绑定的审核状态，不能沿用旧状态文件。

## 题目录入：完整阅读题整组录入

- 覆盖层必须开启 `group_leading_context_questions`：把文章及"下一个阅读提示或顶层大板块边界"之前的**全部所属题**合并为一个 `LEADING_CONTEXT` 题块。
- `leading_context_patterns` 负责定位阅读提示。提示行本身不录入，后续顶层题仍独立。
- 「（一）高考专练 / （二）典题专练」这类题内子板块：**既不截断题块，也不进入最终 F1 选区**。由 `question_input_excluded_patterns` 标记。
- 无原生表格时，执行层在**不保存的临时富文本副本**中剔除标题后整组录入；普通媒体和 VML 装饰对象随富文本保留。标题与原生表格共存时**停止并复核**。
- 题答核对用 `infer_grouped_question_ids()` 展开内部题号，**不能只比较题块数**。
- 新项目应由覆盖层显式选择"只随首题"还是"完整阅读整组"，不要改全局默认。

当前成果：44 份题目文档 → 296 个录入题块，展开后覆盖 400 道原题。

## 对点练答案清洗

入口 `tools/clean_zhongmei_chinese_answers.py`，回归测试 `test_zhongmei_chinese_answer_cleaner.py`。

- 先 `--preflight-only` 整批只读预检，确认通过后再去掉该参数批量输出 `对点练案N_已清洗.docx`。
- 只处理严格命名的 `对点练案N.docx`。
- 遇到未知答案标记、表格答案或题号不连续，**整批停止**，不猜测清洗。
- 无解析题显式补空白 `解析：`。

当前成果：44 份、400 题、409 个答案块，56 道缺源解析的已补空白解析。

## 文言文答案清洗

入口 `tools/clean_zhongmei_classical_chinese_answers.py`。

- 运行前严格递归配对整批题答。
- 双篇文档**保留各篇原题号重置**；仅 `20《苏武传》` 将原 `1、2、5、6` 修正为 `1、2、3、4`。
- 翻译语句统一按「全部 `(n)答案` 连续排列 → 单一 `解析：` → 全部 `(n)得分点`」输出。
- 录入时每个小题用 F4，**整组解析只用一次 F3**；即使只有一个翻译小题也保留 `(1)` 并走 F4。
- 得分点全部移入解析。已知图片字按哈希恢复；遇未知图片或结构异常**整批停止**。

当前成果：28 份 `_已清洗.docx` + 28 份审核状态，154 个录入题块、196 个源答案标记、33 个翻译题块、74 个小题、330 个得分点。

## 答案录入注意

- **标题必须剥离。** 训练标题、题型小标题、「阅读下面……完成题目」提示只供人工阅读；答案解析器必须把它们视为题块边界，F2/F3/F4 选区不得包含标题。旧合并文档里粘在解析末段的标题也要剥离。
- **WPS 活动文档纠偏。** 文言文答案录入时若发现 WPS COM 的 `ActiveDocument` 仍在项目 `文言文/` 原题目录，应映射到 `答案/文言文答案/` 下同层级、同名的 `_已清洗.docx`。必须先验证目标文件存在**且审核门禁通过**，才能打开并激活。**禁止为绕过门禁直接扫描原题。**
- `①②③…` 是单题答案内部列点，整段只用一次 F2；只有明确 `(1)(2)…` 小问和完整阅读组才连续用 F4，同组各小题解析合并后只录一次 F3。
