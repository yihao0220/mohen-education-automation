# Source ActionPlan 取消段落坐标与 WPS 全量绑定

## L1 摘要

- 模块：题目录入 / ActionPlan / WPS Range
- 日期：2026-08-02
- 状态：代码与离线回归完成；Windows/WPS 两表格代表样本 8/8 实机选区通过
- 结论：Source ActionPlan 只描述“录什么”，不再输出或执行 DOCX 段落坐标；Windows 在第一次人工确认前直接读取当前 WPS，一次性生成全部动作的 `wps_ref`，后续选区只认 WPS 运行时坐标。

## L2 现象与根因

- 《课时分层作业5》含两个原生表格，DOCX 顶层段落与 WPS `Document.Paragraphs` 的计数不同，实测偏移由 `+12` 累积到 `+24`。
- 第 5 组修正为 WPS `62–70` 后，第 6 组在逐组懒绑定时把前置无文字图片段和真实题目段计算成两个范围，触发多重命中阻断。
- 根因不是电脑或字符编码差异，而是旧流程把 DOCX 段落号当作 WPS 首选坐标，失败后才逐组搜索；Source ActionPlan 与生产坐标的职责没有彻底分开。

## L3 改动与验证

- ActionPlan schema 升级到 `1.1`；`source_ref` 只保留首尾文字锚点、表格规格与表格/媒体/公式数量，移除虚拟节点号、DOCX 段落号、媒体段落号和公式段落号。
- 新增 WPS 全量绑定：先定位所有题组开头，再在当前题组与下一题组开头之间定位结尾；校验动作顺序、唯一性和实际表格数量，成功后生成每组 `wps_ref`。
- 新计划未绑定 `wps_ref` 时禁止预览；预览和受控执行均只使用已绑定 WPS 范围。旧 `1.0` 计划保留兼容分支，不作为新计划坐标来源。
- 回归覆盖来源计划无段落号、表格展开、前置无文字图片、后续动作真实多重命中、未绑定阻断和旧试点兼容。
- 核心定向测试 33 项通过；扩大地理与未来生物相关回归为 46 项通过、2 项因默认样本路径跳过、1 项既有复合答案题号失败。显式指定未来生物真实样本后，题图数量证据为 1 且来源计划不再暴露媒体段落号。
- 真实《课时分层作业5》Source ActionPlan 为 8 个动作、schema `1.1`，所有动作均无段落坐标；源 SHA256 前后不变。Mac 只能验证来源计划和绑定算法，不能声称 Windows WPS 的最终 `wps_ref` 已通过。
- 37 份莞美地理的新计划共 284 个动作，全部无坐标泄漏且源哈希不变；历史题答流程基线为 298 个 F1/答案块。差异只出现在《课时分层作业22》（15→8）和《课时分层作业24》（13→6），原因是目录强制绑定 `geography` 后按材料范围合并了原先分开的 14 组。该差异不是取消段落号造成的，但在题答批量生产前必须单独对齐，当前 Windows 包只用于《课时分层作业5》无按键预览验收。
- Windows/WPS 实机验收：用户运行 UTF-8 测试包后确认《课时分层作业5》开始前全量绑定成功，随后 8 组选区全部正确。第 5 组保持排除“素养培优练”，第 6 组不再因前置无文字图片误报多重命中。用户未粘贴最终 JSON 回执，因此这里只记录人工确认，不补写未提供的回执字段。
