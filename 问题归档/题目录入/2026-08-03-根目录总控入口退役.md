# 根目录总控入口退役

## 结论

根目录任务面板已退役。日常生产恢复为三个直接入口：题目录入、答案格式清洗、答案录入；本机已有的 `工作台路径配置.json` 保留不动，但系统不再读取它。

## 当前功能链

1. `墨痕快刀/main.py` 负责扫描当前 WPS 原题、识别题块并执行 F1。
2. `格式处理/main.py` 负责清洗原始答案；提供对应题目文档后，同时生成审核清单和与清洗文件内容绑定的审核状态。
3. `答案录入/answer_input.py` 负责 F2/F3/F4；只有审核状态为通过且答案文件大小、SHA256 未变化时才放行。
4. `tools/build_regression_manifest.py` 独立生成回归样本清单，不再依赖根目录入口。

## 问题与证据

- 实际生产一直直接运行题目录入和答案侧脚本，根目录任务面板没有进入用户的日常操作路径。
- 根目录 `main.py` 同时承担任务扫描、流程编排、自动审核和回归清单生成，删除前不能直接丢弃后两项仍被测试或门禁依赖的能力。
- 答案录入原本仍提示用户返回根目录总控，与实际操作方式不一致。

## 改动

- 删除根目录 `main.py` 与仓库内的 `工作台路径配置.example.json`。
- 保留本机忽略文件 `工作台路径配置.json`，避免删除用户已有路径资料。
- 将自动审核决策迁入 `shared_core/review_gate.py`，由 `格式处理/main.py` 在生成审核清单后直接写入审核状态。
- 将回归清单构建逻辑迁入 `tools/build_regression_manifest.py`，并修复 Windows 路径在 Mac 测试时无法正确取得文件名的问题。
- 删除任务面板测试，新增直接答案清洗生成绑定审核状态的回归测试。
- 更新 VS Code 入口、README、CLAUDE 和答案录入提示，不再把根目录总控作为现行入口。

## 影响与风险

- 不再提供自动扫描多目录、配对题答材料和显示任务阶段的面板。
- 题目录入、答案清洗、答案录入的业务逻辑保留；答案审核门禁没有降低。
- 答案清洗时如果没有提供对应题目文档，无法生成审核清单和放行状态，答案录入会继续拦截。
- 本次没有修改任何 `wps_helper.py`，没有触碰仓库外原题、答案或莞美交付产物，也没有执行 Git 提交或推送。

## 验收

- 排除四个已知外部样本/无关失败文件后的离线回归：`196 passed, 42 skipped, 7 subtests passed`。
- 全量回归：`216 passed, 55 skipped, 20 subtests passed`，另有 `6 failed, 10 errors`。其中南城数学与数学模板共 10 个错误及 4 个失败来自 Mac 无法读取硬编码的 Windows `D:\墨痕教育题目\...` 样本；其余 2 个失败分别是已有地理答案题号预期差异、众美文言文 Windows 路径映射，与本次总控退役无关。
- Windows/WPS 实机按键未在 Mac 验证；本次没有改变 F1/F2/F3/F4 执行实现。
